# Pixel-Art Studio

A browser-based visual design editor with a professional dark workspace and a black / yellow / white identity. English is the default; Arabic RTL is available from the language toggle.

## Run
Open index.html through VS Code Live Server or any static HTTP server. Fabric.js and Google Fonts are loaded from CDNs.

## Current capabilities
- Design workspace with templates, elements, text, uploads, background and layers panels
- Editable Fabric.js canvas: shapes, text, images, selection, transform, ordering, visibility and locking
- Object inspector for position, dimensions, rotation, color and opacity
- Multi-page documents, undo/redo, browser-local autosave, JSON project import/export
- PNG/JPG/SVG export at selectable raster scale
- Responsive layout, keyboard shortcuts and English/Arabic interface

## Honest limitations
This is an actively-developed foundation, not yet a Canva or Photoshop replacement. Cloud sync, collaboration, large commercial template/media libraries, advanced typography, true alpha eraser, masks, blend modes, non-destructive adjustment layers, pen/path editing and PSD fidelity are not implemented yet. Autosave is local to this browser only.
